# Screenshot assets

Production screenshots are intentionally not fabricated. When capturing a
real app, place files in:

- `docs/assets/screenshots/android/client/`
- `docs/assets/screenshots/android/controller/`
- `docs/assets/screenshots/ios/client/`
- `docs/assets/screenshots/ios/controller/`

Use descriptive names such as `dashboard-online.png` and record the app
version, OS, device/simulator, and capture date in the pull request. Remove
tokens, pairing codes, network credentials, personal data, and private
endpoints before committing. Link only verified images from documentation.
