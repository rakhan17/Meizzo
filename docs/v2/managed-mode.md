# Managed Mode

Managed Mode is not implemented in the current repository. It must not be
represented by a cosmetic switch.

A compliant implementation requires organization identity, legitimate Android
Enterprise provisioning, enrollment state, policy synchronization, audit
events, and clear ownership indicators. Device Owner/Profile Owner status does
not silently authorize screen capture, camera, microphone, location, files, or
input injection. The first V2 deliverable for this area is an enrollment and
capability-status design, followed by device-policy integration on supported
provisioned devices.
