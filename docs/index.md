# MEIZZO documentation

MEIZZO is a beta device-assistance ecosystem with separate Client and
Controller applications for Android and iOS. Start with the [quick
start](getting-started.md), then choose the [user manual](user-guide.md) or
[developer setup](development.md).

| Client operator | [Client guide](client-guide.md) |

Build and runtime evidence is separated in [implementation
status](implementation-status.md). Simulator launch is not equivalent to
physical-device or end-to-end network validation.
