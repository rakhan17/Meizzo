# Support

Start with the [user guide](docs/user-guide.md), [troubleshooting guide](docs/troubleshooting.md),
and [FAQ](docs/faq.md). Check the release notes before reporting a regression.

For a useful issue, include the app name, package or bundle identifier,
version, platform, OS version, device model, backend endpoint type (without
credentials), reproduction steps, expected behavior, actual behavior, and
sanitized logs. Attach screenshots only when they contain no private data.

Do not publish tokens, passwords, private keys, pairing codes, network
credentials, or personal information. Security vulnerabilities belong in
[SECURITY.md](SECURITY.md), not in public support issues.
